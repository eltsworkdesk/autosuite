# Archive

early planning docs — kept for the record, not for orientation. Several are
now inaccurate as a description of the current build (e.g. `ROADMAP.md`
here still lists the CRM and dealer dashboard as unbuilt "Phase 3" work).

If you're trying to understand the project as it is today, start with
[`README.md`](../../README.md) and [`docs/ONBOARDING.md`](../ONBOARDING.md)
instead.
